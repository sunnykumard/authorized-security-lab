# Evidence Directory

This directory is reserved for minimal, non-sensitive evidence collected only under an approved Rules of Engagement.

- Do not commit credentials, tokens, personal information, raw sensitive logs or confidential screenshots.
- Keep evidence local unless the asset owner explicitly approves another storage location.
- Redact sensitive values in a separate copy; preserve originals securely where required.
- Record evidence metadata and SHA-256 hashes in `evidence-register.csv` where appropriate.
- Follow the owner-approved retention and disposal policy.

Security testing is not authorized until written approval and all required signatures are obtained.
